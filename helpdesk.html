IT Help Desk Procedure

Employees should report technical problems to the IT help desk instead of making major changes to their computers or network settings themselves.

Help Desk Process

  1. User reports the problem.
  2. Help desk creates a support ticket.
  3. Priority is assigned.
  4. Technician investigates the problem.
  5. Problem is resolved.
  6. User confirms the solution.
  7. Ticket is closed.

Priority

Problems affecting an entire branch or important company services should receive a higher priority than minor problems affecting one employee.

Important

Employees should provide as much information as possible when reporting a technical problem. This helps the IT technician identify and resolve the issue faster.
